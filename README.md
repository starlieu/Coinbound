# Coinbound
Jeu de simulation gratuit et local : marchés, cours, conversions et soldes sont fictifs et sans valeur réelle. Aucun service financier n'est appelé. L'état de jeu est sauvegardé sur l'appareil.

## Développement
`npm install` · `npm run dev` · `npm run build` · `npm run preview`

GitHub Actions construit et publie le site sur Pages avec le préfixe `/Coinbound/`.

## Mobile
Une APK React Native est prévue ; `mobile/` est réservé au futur client natif.
